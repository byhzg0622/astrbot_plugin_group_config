# 分组配置管家（astrbot_plugin_group_config）

分组 / 整群 / 子会话批量下发人格、模型与插件开关，并用「人格源」让选中的人格成为一切生成的源头。

**版本**：v1.0.0 ｜ **适用**：AstrBot >=4.5,<5 ｜ **依赖**：无第三方库

## 解决什么问题

AstrBot 的人设、模型和插件开关默认全局生效。想让 A 群用某人设、B 组换一套模型、某个子会话单独调整，只能逐个会话手改，会话一多就难以维护。本插件在 AstrBot 原生会话规则之上，加了一层「分组 / 整群 / 子会话」的定义与管理。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 全局默认 | 所有会话的兜底层配置 |
| 分组 | 跨群的逻辑集合（a / b / c…，带优先级）。成员 = 显式加入的会话 + 通配规则（如 `default:GroupMessage:*_1053676331`），命中规则的新会话自动入组 |
| 整群 | 一个物理群聊。开启「单独记忆」后，群里会有多个互相隔离的子会话 |
| 子会话 | 群内的独立记忆单元：可以单独覆盖某几项配置，也可以一键清除覆盖、恢复继承 |
| 分组内 / 分组外 | 分组内 = 该组全体成员；分组外 = 已知会话全集 − 该组（补集）。两个方向对称批量 |
| 生效链 | 某会话的四类配置分别来自哪一层，可在面板与 `/分组配置 me` 中查看 |
| 人格源 | 勾选后，该层选中的人格即「决定性人格」，随继承生效；主动消息、动态生活状态等生成也会用它 |

继承顺序（低 → 高）：**内置默认 < 全局默认 < 分组设定 < 整群设定 < 子会话覆盖**。每层只保存「改过的项」，没设的项自动向上继承；清除某层字段即恢复继承。

## 功能

1. **按作用域设置人格**：全局 / 分组 / 整群 / 子会话四级，各自选人格。
2. **按作用域设置模型**：为分组或整群指定 provider，不改动全局默认。
3. **按作用域开关插件**：在指定会话里关掉某个插件，其他群不受影响。
4. **分组批量下发**：把一套配置应用到整个分组，先预览影响面再确认执行。
5. **分组外（补集）批量**：一键应用到「某分组以外的所有会话」，与组内批量对称。
6. **整群设定 + 子会话继承**：给整个群设一份配置，之后新出现的子会话自动遵循；单个子会话仍可单独改动或恢复继承。
7. **批量安全**：执行前自动生成快照，支持回滚；单点失败不影响整批。
8. **双入口管理**：群聊指令快速操作 + WebUI 管理面板可视化批量操作。

## 人格源（决定性人格）

在人格选择旁多一个勾选框：勾上后，当前层选中的人格成为该会话的**决定性人格**。全局 / 分组 / 整群 / 子会话四层各有一个勾选框，随继承生效——高层可以只改人格不关开关，也可以只关开关不改人格。

它不只影响普通聊天：主动消息、动态生活状态等插件在生成时选人格，也会拿到这份决定性人格。

| 场景 | 效果 |
| --- | --- |
| 普通聊天 | 按决定性人格回复（会话规则最高优先） |
| 主动消息 | 对话人格同步对齐到决定性人格 |
| 动态生活状态 | 按「人格跟随插件」名单 + 全局人格源重定向 |
| 无会话上下文的全局生成 | 取全局层的决定性人格 |

实现不修改任何第三方插件文件，wrap 幂等安装、可整层卸载；未勾选人格源的会话或调用保持 AstrBot 原生行为。机制见 [docs/DESIGN.md](docs/DESIGN.md) 第 11 节。

## 典型场景

1. **整群统一人设**：在「整群」层给某群设人格 P → 群内现有会话与之后新出现的子会话都用 P。
2. **只改一个子会话**：给某个子会话单独设人格 Q（子会话覆盖）→ 只有它变，整群其余仍是 P；清除覆盖即恢复 P。
3. **分组统一换模型**：把若干群加进分组 a，给 a 设模型 M → a 内全部生效；再用「分组外」把默认模型下发到其余会话。
4. **某群关掉一个插件**：在该群或所在分组的插件开关里 off 掉它，其他群继续可用；开启会话闸门后，该群内这个插件连钩子与 LLM 工具也不会被调用。
5. **新会话自动进组**：给分组 a 加一条通配规则（如 `default:GroupMessage:*_1053676331`），之后命中规则的新子会话自动入组并继承 a 的配置。

## 安装与升级

1. 把本目录内容放进 AstrBot 的 `data/plugins/astrbot_plugin_group_config/`（替换原版目录即可）。
2. 在 WebUI 插件页重载本插件，或重启 AstrBot。
3. 无第三方依赖，开箱即用。

**从原版（未含「人格源」的版本）升级**：插件名、指令、面板与数据目录都与原版一致，**直接用本目录整体替换原版目录即可升级**；既有的分组 / 整群 / 子会话配置（`store.json`、`registry.json` 等）原样沿用，不需要重新配置。

从更早版本升级：直接覆盖目录后重载即可。数据保存在 AstrBot 的 data 目录，重装不丢。

## 配置

插件配置项位于 AstrBot 的插件配置页：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `session_plugin_gate` | `false` | 会话级插件闸门：开启后，被分组配置关掉的插件在该会话被调用时直接跳过，覆盖消息/指令、钩子、结果装饰、LLM 工具四类路径，只拦截、不改参数。修改后重载本插件生效 |

其余管理动作都在面板或指令里完成，不需要改配置文件。

## 使用

**面板**：插件详情页进入「分组配置管理」，包含分组树与会话全集、批量页（组内 / 组外、预览、执行、回滚）、四类作用域编辑器（人格 / 模型 / 服务开关 / 插件开关）以及生效链查看。

**常用指令**（群聊发送，前缀 `/分组配置`，子命令参数以插件提示为准）：

| 指令 | 作用 |
| --- | --- |
| `/分组配置 me` | 查看当前会话的生效链，四类配置各自来自哪一层；开启人格源时显示 ★决定性人格及其来源层 |
| `/分组配置 group ...` | 新建 / 删除分组、加入或移出本会话、增删通配规则、查看分组与优先级 |
| `/分组配置 batch group` | 批量应用到分组内：先预览，再 confirm / cancel |
| `/分组配置 batch outside` | 批量应用到分组外（补集），预览后确认 |
| `/分组配置 cluster show / set / reset` | 查看、设置、重置本群的整群设定 |
| `/分组配置 sub show / set / reset / takeover` | 查看子会话生效链、单独覆盖、恢复继承、重新接管 |
| `/分组配置 global / cluster / sub set src on/off` | 开启或关闭某一层的人格源勾选 |
| `/分组配置 persona <名称> src` | 选人格的同时直接勾上人格源 |

## 数据与备份

- 配置数据保存在 AstrBot 的 data 目录（本插件专属子目录），不写在插件目录，升级 / 重装不会丢。
- 主存储记录全局、分组、整群、子会话各层配置，另有一份会话全集登记簿。
- 每次批量执行前会自动快照，保留最近 10 次，可在面板回滚。
- 迁移或备份时，复制整个插件数据目录即可；数据只存本机，不上传任何地方。

## 注意事项

- **会话闸门默认关闭**：不开闸门时，配置仍会写入 AstrBot 原生会话规则；闸门只额外保证「被关掉的插件在该会话真的不被调用」。
- **不改第三方文件**：不修改 AstrBot 本体或任何第三方插件文件，只写 AstrBot 原生的会话规则；停用插件即可让运行时拦截完全退出。
- **首条消息差异**：新子会话的首条消息插件过滤可能按默认放行，第二条起完全按配置生效；人格与模型首条即正确。
- **拦截边界**：插件的 WebUI 路由、自建后台任务、Provider 等没有「会话」概念，不受会话级开关影响。
- **批量前先预览**：对大量会话执行前建议先预览影响面；执行时会自动快照，可回滚最近一次批量。
- **人格源默认关闭**：未勾选的会话与调用保持 AstrBot 原生行为；全局层的勾选也会影响无会话上下文的生成（如动态生活状态的每日生活状态）。

## 设计边界

- 只做「定义层 + 同步」：配置最终写成 AstrBot 原生会话规则，与官方「自定义规则」同源同构。
- 不做跨实例导入导出 / 云同步，也不做按用户（个人）维度的配置。
- 详细设计见 [docs/DESIGN.md](docs/DESIGN.md)，实现进度见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 常见问题

**改了配置但没立刻生效？** 会话闸门相关设置修改后需重载本插件；其余分组配置保存后即时同步到目标会话。

**新子会话为什么没继承？** 确认给的是整群或分组层配置；新会话会自动继承上层，若它被单独覆盖过则保持自身设置，清除覆盖即恢复。

**分组外补集包含哪些会话？** 本插件已知的会话全集：底层会话记录、消息中自动发现的会话、手动导入的会话。刚出现的新会话会在首条消息后登记。

**人格源和普通人格设置有什么区别？** 普通人格主要影响走核心人格解析的普通聊天；勾上人格源后，主动消息、动态生活状态等按自己逻辑选人格的插件也会拿到这份决定性人格。
